# 更新记录：2026-11-09

## 初始代码骨架

- 建立唯一入口 `local-pdf-toolkit.py`，用于加载配置、初始化统一日志并启动本机网页服务。
- 新增标准库 HTTP 服务，提供首页、`/api/status` 和工具目录占位接口。
- 服务仅允许绑定 `127.0.0.1` 或 `::1`，符合本机运行要求。
- 新增统一 HTML 首页，按 PDF 工作流展示工具分组和接入状态。
- 新增配置加载模块、`config.yaml`、`common.env.example`、`.gitignore`、依赖清单和项目 README。
- 日志使用根目录 `logging_config.py`，写入 `logs/` 并按既定大小轮转。

## 已确定的整合边界

- 首批整合 `PdfTextMarker`、`CopyPdfPline`、`PDFPageReplacer`、`GetPdfText`、
  `GetPdfInfo` 和 `GetLocInPdf` 的 PDF 功能。
- 同时纳入 `PdfStamp`、`Frame2Pdf` 等其他项目中确认属于 PDF 处理的功能。
- `GetPdfInfo` 与 `GetLocInPdf` 先分别保留，待分析源码后再考虑共享实现。
- `local-pdf-toolkit.py` 是唯一用户启动入口；来源项目原有入口和接口不作为新项目入口保留。
- PDF 修改和输出由本机 Bluebeam Revu 20 eXtreme 执行；Python 可用于读取、搜索、渲染、
  OCR 前后处理和坐标分析等辅助工作。
- 本地 AI 服务由外部项目管理；本项目只调用服务，不负责服务配置和生命周期管理。AI 环境
  参数待用户补充后接入相应工作流。
