## Bluebeam 调用边界排查

- 本机 `ScriptEngine.exe` 接受脚本命令，但直接执行页面拆分命令返回 `No Active Document`（退出码 -3）。
- Revu 20 官方帮助说明脚本从 Revu Script Manager 的单文件或批处理上下文运行；网页工作流需要
  建立 Bluebeam 宿主文档上下文后才能安全执行修改，不能把当前 CLI 当作已验证的无界面 PDF 后端。
- 该调用适配仍在开发中；当前已接入的元素提取、OCR 和页数校核都只读 PDF，不会改写 PDF。
